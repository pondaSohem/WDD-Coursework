Home page

Technical Description

For the the home page i first started by dividing the page into sections as

  • Header
    • Navigation Bar
    • Logo
  • Main Content
    • Face Section
    • Scroll Gallery
    • Featured Content
  • Footer
    • Page Editor link
    • Validation Page Link


    Then i moved into making cards and containers for each of the sections and specially the Scroll able card container for the content gallery. The home page makes use of various HTML and CSS to make it functional. The Key HTML tags used are

    For the styling i used CSS to create a responsive layout using (display: grid) to create a (.parent) that provides the whole grid a structure and divides it so that i can add the different cards in specific order and ensure the page looks good on all devices. following that i used (display: flex) to create a scrollable gallery section and to make the content cards align in a row and be scrollable horizontally. For the styling of the cards i used (box-shadow) to give them a 3D effect and (border-radius) to make the corners rounded. I also used (hover) function to add a CSS styled gradient that pop up when a cursor was on top and show the basic image Description and a small text showing which Students content page it leads to. For the addition of javascript it was used to allow for the intercation with the scroll gallery to where it scrolls left and right when the buttons are clicked. The other use of javascript was the back to top button which was made to appear when the user scrolls down and when clicked it takes the user back to the top of the page with it being styled using javascript to be a vibrant color and have a hover effect to make it more interactive.

    Accessibility

    To ensure accessibility, I implemented semantic HTML tags, made the button vibrant colors and well labeled, provided alternative text for images, and ensured sufficient color contrast for readability. The text is also clear and concise, and the layout is simple and easy to navigate. I also made sure that the page is responsive and works well on different devices, which is important for accessibility.

Content Page

Technical Description

To implement the content page, I used a combination of HTML and CSS to create a structured layout that is both visually appealing and easy to navigate. The page is designed to be responsive, ensuring that it looks good on all devices. To start of i used (Header) Tags to create a clear hierarchy of information, making it easier for users to understand the content. I also used (div) tags to create sections for different types of content, such as text, images, and videos. For styling, I used CSS to create a clean and modern design. I chose a color palette that is visually appealing and easy on the eyes, and I used typography to create a clear and readable layout. I also used CSS to create a responsive design, ensuring that the page looks good on all devices. I again us the .grid and .flex display properties to create a structured layout that is both visually appealing and easy to navigate. I used the img src tag to insert images and styled them to fit the content sections. I also used CSS to create a hover effect on the images. Overall, the combination of HTML and CSS allowed me to create a content page that is both functional and visually appealing.

Accessibility

To make this page more accessible I used the div tags along with grid to create an open layout that allows the data to be spread around and visually apealing.
