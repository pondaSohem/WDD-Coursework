AMAZE - SDG 4 Quality Education Website

A group coursework project for Web Design and Development, focused on **UN Sustainable Development Goal 4: Quality Education**. This website aims to educate, engage, and empower users to take action toward inclusive and equitable education for all.

| Student 2 | Interactive Features Lead | Splash Screen, Action Impact Simulator, Content |

Features

Student 1
- **Home Page** - Mission cards, interactive Gallery linking to content pages, The whole template for HTML and CSS for the webpages
- **Gallery** - Click-to-expand image gallery with hover effects

Student 2
- **Splash Screen** - 4-second auto-redirect with CSS loader and skip button
- **Action Impact Simulator** - Interactive tool with 7 action cards

Student 3
- **Feedback Page** - Scrollable programme directory with feedback form and live character counter * does not have functionality yet *
- **Team Page** - Expandable team member cards with hover effects

Student 4
- **User Profile** - JavaScript prompt-based profile builder with 10 fields, progress bar, and username validation
- **Sitemap** - Interactive SVG diagram showing website hierarchy with clickable nodes

Every Student
- **Content Page** - SDG Targets 4.1 through 4.5 information with statistics, action lists, and internal navigation

Getting Started (Local Installation)

Prerequisites
- A web browser (Chrome, Firefox, Safari, Edge)
- A code editor (VS Code, Sublime Text, etc.) - optional, for viewing code
- Git (optional, for cloning)

### Method 1: Clone with Git

```bash
# Clone the repository
git clone https://github.com/pondaSohem/WDD-Coursework.git

# Navigate to the project folder
cd WDD-Coursework

# Open index.html in your browser
open splash.html   # macOS
start splash.html  # Windows
xdg-open splash.html # Linux
```

### Method 2: Download ZIP

Go to https://github.com/pondaSohem/WDD-Coursework

1. Click the green "<> Code" button

2. Select "Download ZIP"

3. Extract the ZIP file to your desired location

4. Double-click splash.html to open in your browser
