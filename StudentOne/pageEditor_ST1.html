Home page

Technical Description

The Home Page is developed using HTML5 and CSS3 to create a responsive and user-friendly interface. The document begins with the <!DOCTYPE html> declaration and uses the <html lang="en"> element to ensure proper rendering, accessibility, and SEO. The <head> section includes meta tags for character encoding and responsiveness, along with links to external stylesheets and fonts for consistent design.

The page structure is organized using semantic elements such as <header>, <nav>, <main>, <section>, and <footer>. The navigation bar is built using a list of links and styled with Flexbox, while being fixed at the top of the page for easy access. Content is divided into sections and containers using <div> elements for layout and styling.

CSS is used to design reusable components such as cards and containers with consistent colors, spacing, and shadows. Layout techniques like Flexbox and Grid help organize content, while hover effects, transitions, and overlays enhance interactivity. Images include alt attributes for accessibility, and a horizontal scrolling gallery is implemented for visual content display.

A footer section provides additional links and information, and a “Back to Top” button is included using fixed positioning and simple JavaScript for interactivity. Overall, the page combines semantic HTML and modern CSS techniques to create a structured, accessible, and visually engaging homepage.

Accessibility

To ensure accessibility, I implemented semantic HTML tags, made the button vibrant colors and well labeled, provided alternative text for images, and ensured sufficient color contrast for readability. The text is also clear and concise, and the layout is simple and easy to navigate. I also made sure that the page is responsive and works well on different devices, which is important for accessibility.

Gallery Page

Technical Description

The Gallery Page is developed using HTML5, CSS3, and JavaScript to create an interactive and responsive image display. The page uses standard HTML structure with semantic elements such as <header>, <nav>, <main>, and <footer> to improve accessibility and organization. A navigation bar is included at the top using a list of links, styled with CSS and fixed positioning for easy access.

The main gallery layout is created using CSS Grid, which arranges the images into a structured two-column layout. Each image is placed inside a <div> container with the class .gallery-image-card, maintaining a consistent aspect ratio for uniform appearance across different screen sizes.

Each gallery item uses a flip-card design, where the front side displays an image and the back side shows descriptive text. This effect is achieved using CSS properties such as transform, perspective, and backface-visibility. Hover effects and overlay text are also applied using transitions to enhance user interaction.

JavaScript is used to add interactivity by allowing users to click on each card to flip between the image and its description. Event listeners are implemented for both mouse clicks and keyboard inputs to improve accessibility. Additional scripts ensure consistent image sizing and handle errors if images fail to load.

Overall, the page combines structured HTML, modern CSS techniques, and JavaScript functionality to create an engaging and user-friendly gallery that visually represents key aspects of quality education.

Accessibility

To make the gallery page more accessible , I made the images the button itself so it is easier to switch to the text and provide a clear label for each image along with a line to click back to view the image.

Content Page

Technical Description

This content page is developed using HTML5 and CSS3 to present structured information about SDG 4: Accessible and Affordable Education. The page uses semantic elements such as <header>, <nav>, <main>, and <footer> to improve accessibility and organization. A navigation bar is included at the top for easy access to other pages.

The main layout is created using CSS Grid (display: grid), which organizes content into multiple sections using defined grid columns and rows. Each section is placed using specific grid classes (e.g., .divC1, .divC2) to control positioning and structure.

Content is grouped using reusable containers such as .container, .card, and .head-card, which provide consistent styling including spacing, colors, and shadows. Images are added using the <img> tag and styled to be responsive using width and max-width properties.

Lists (<ul> and <li>) are used to present key points clearly, improving readability. CSS is also used to style image cards and maintain layout consistency across different screen sizes.

A footer section provides navigation links and additional information, while a “Back to Top” button is implemented using fixed positioning and JavaScript for basic interactivity. Overall, the page combines structured HTML and CSS Grid layout to present educational content in a clear, organized, and responsive manner.

Accessibility

To make this page more accessible I used the div tags along with grid to create an open layout that allows the data to be spread around and visually apealing.

External resources are properly referenced, and links are clearly labeled to avoid misleading navigation.
