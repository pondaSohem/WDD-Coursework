Splash Page

Technical Description

The Splash page is a single full-screen introductory screen that auto-redirects the user to the home page after a 3-second countdown. The page is structured around one main <div> with the ID #splash, which wraps all visible content including the heading, description paragraph, circular countdown loader, and skip button.
The heading uses <h1> with a class of .logo to display the page title. Below it, a <p> tag with ID #para is positioned at the bottom of the screen using position: absolute, bottom: 40px, and transform: translateX(-50%) to keep it horizontally centred.
The circular countdown loader is built using an inline <svg> with a viewBox of 0 0 100 100. It contains two <circle> elements: a static background circle with class .circle-bg, and an animated progress circle with class .circle-progress and ID #circleProgress. The countdown number is displayed in the centre using a <span> with ID #countdown, overlaid on the SVG using CSS positioning within the .circle-container wrapper.
All countdown logic is handled with JavaScript inline in the page. The circle's stroke animation uses strokeDasharray and strokeDashoffset, calculated from the circumference formula 2 * Math.PI * 40 ≈ 251.2. A setInterval() decrements the counter every 1000ms, updates countdown.textContent, and shrinks the visible stroke by adjusting strokeDashoffset proportionally. When the count reaches zero, clearInterval() stops the timer, the .fade-out class is added to #splash triggering a CSS opacity: 0 transition over 0.4 seconds, and window.location.href redirects to the home page after an 800ms delay.
A skip button styled with class .skipbutton is fixed to the bottom-right corner using position: fixed, bottom: 30px, and right: 30px. It has a hover effect that changes its background to #1abc9c and scales it up using transform: scale(1.1). Clicking it triggers the same redirectWithFade() function via an addEventListener("click", ...) with e.preventDefault() to prevent default anchor navigation and ensure the fade transition plays first.

Accessibility

All images include descriptive alt text. Form fields use <label> tags properly associated with inputs. <fieldset> and <legend> group form sections logically. Error messages appear near relevant fields with visible color contrast. The page uses semantic HTML elements like <header>, <main>, and <footer> for screen reader navigation. A "Back to Top" button provides easy keyboard navigation.

Action Impact Simulator Page

Technical Description

The team page displays four student profiles using a card-based layout. Key HTML tags include <header> for navigation, <main> for content, and <footer> for page footer. Each team member is represented using an <a> tag wrapped around an <img> and a <div class="info-card">. Unordered lists <ul> and <li> display each member's responsibilities.

Key CSS properties: display: grid or flex arranges cards in a responsive gallery. position: relative on image containers and position: absolute on overlay text creates hover effects. transform: translateY(100%) hides overlay text initially, changing to translateY(0) on hover to reveal names. transition provides smooth animation. object-fit: cover ensures images fill their containers properly. box-shadow and border-radius add visual polish to cards.

JavaScript is not used on this page. All interactivity comes from CSS hover effects only. The image overlay that reveals student names on hover, the subtle zoom effect on images, and the card shadows are all achieved with pure CSS. No form validation, dynamic content loading, or event handling is implemented.

Accessibility

All images include descriptive alt text with student names. The page uses semantic HTML elements like <header>, <main>, <footer>, and <ul> for proper document structure. The active page link is highlighted in the navigation bar. Heading hierarchy starts with <h1> for the main title, then <h3> for student names inside cards. The entire card is clickable as an <a> tag, making it keyboard accessible. Color contrast meets readability standards.

Content Page

Technical Description

This content page uses basic HTML and CSS to present information about UN Sustainable Development Goal Target 4.1. Key HTML tags include <header> for the navigation bar, and an internal nav bar for easier navigation between different sections of the content page. The nav bar and the internal nav bar is created using a <nav> with an unordered list <ul> for menu links, and <main> to contain the primary page content. <div class="head-card"> introduces the topic with a main heading <h1> and paragraph <p>. <div class="container"> and <div class="card"> provide structural containers for different content sections, with the card class typically offering visual separation through background styling defined in the global template CSS. <img> tags embed educational photographs with alt attributes for accessibility and inline styles controlling width, float positioning, border radius, and margins to create wrapped text layouts.

The page organizes information into four logical sections: overview, key elements, challenges, and progress. Each section combines images with text to reinforce learning. In the key elements card, an unordered list <ul> with list items <li> presents the five core principles of Target 4.1 including free education, equitable access, and quality learning. This list structure helps screen reader users understand the relationship between items and allows keyboard navigation through each point individually. The challenges and progress sections use floated images with text wrapping, achieved through inline CSS properties float: left or float: right, margin-right, and margin-left. These properties create a magazine style reading flow where images sit beside their accompanying paragraphs rather than forcing vertical scrolling through large image blocks.

The footer contains <div class="foot-container"> with a copyright heading <h4> and an unordered list <ul> of footer links including the page editor and validation pages. The back to top button uses a <div class="back-top"> wrapper containing an anchor <a href="#"> with an arrow symbol. JavaScript event listeners for mouseenter and mouseleave dynamically change the button inner HTML and background color, expanding the text from a simple arrow to "Back To Top" on hover. This progressive enhancement improves usability without requiring additional page loads. The button remains fixed during scrolling, ensuring it is always accessible regardless of how far down the page the user has navigated.

Accessibility

This content page prioritizes accessibility through semantic HTML and thoughtful interactive design. The use of <header>, <nav>, <main>, and <footer> creates clear document landmarks that screen reader users can navigate efficiently. The navigation menu structured as an unordered list <ul> announces the number of available links, helping users understand the page structure before investing time in exploration. Every image includes a descriptive alt attribute, such as "Children in a classroom" and "Young girl studying", which conveys the educational context rather than merely describing visual characteristics. This ensures blind users receive the same informational value as sighted users when learning about Target 4.1.

The back to top button includes JavaScript that expands its text on hover or focus, changing from an arrow symbol to the descriptive phrase "Back To Top". This transformation benefits users with cognitive disabilities who benefit from explicit action labels and users with motor impairments who benefit from the enlarged click target area. The button maintains a consistent dark background that contrasts sufficiently with the light page content, ensuring it remains visible regardless of scroll position. The viewport meta tag width=device-width, initial-scale=1.0 prevents automatic zoom out on mobile devices and allows users with low vision to pinch zoom without breaking the layout. When users zoom to 200 percent, the use of percentage based widths and responsive design principles ensures text reflows naturally within its container rather than disappearing off screen or requiring horizontal scrolling.
