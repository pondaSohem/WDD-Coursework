Feedback Page

Technical Description

The feedback page uses basic HTML and CSS to create a functional layout. Key HTML tags include <header> for the navigation bar, <main> for main content, <section> to separate programmes, reviews, and form areas. <fieldset> and <legend> group related form fields. <input type="email">, <input type="date">, and <textarea maxlength="500"> provide built-in validation and character limits. <select multiple> allows multi-selection for interests, and <datalist> gives searchable country suggestions.

Key CSS properties: position: fixed keeps the header visible while scrolling. display: flex with overflow-x: auto creates horizontal scrolling cards. filter: grayscale(100%) makes images black and white, changing to grayscale(0%) on hover for interactive effect. transform: translateY(-3px) and box-shadow add hover lift.

JavaScript is used minimally for three specific tasks. First, a live character counter updates in real-time as the user types in the review textarea, showing remaining characters and changing color when under 20 characters. Second, form validation checks all required fields on submit, displays custom error messages next to invalid fields, and highlights them with red borders. Third, a confirmation message appears upon successful validation, then auto-hides after 4 seconds.

Accessibility

All images include descriptive alt text. Form fields use <label> tags properly associated with inputs. <fieldset> and <legend> group form sections logically. Error messages appear near relevant fields with visible color contrast. The page uses semantic HTML elements like <header>, <main>, and <footer> for screen reader navigation. A "Back to Top" button provides easy keyboard navigation.

Team Page

Technical Description

The team page displays four student profiles using a card-based layout. Key HTML tags include <header> for navigation, <main> for content, and <footer> for page footer. Each team member is represented using an <a> tag wrapped around an <img> and a <div class="info-card">. Unordered lists <ul> and <li> display each member's responsibilities.

Key CSS properties: display: grid or flex arranges cards in a responsive gallery. position: relative on image containers and position: absolute on overlay text creates hover effects. transform: translateY(100%) hides overlay text initially, changing to translateY(0) on hover to reveal names. transition provides smooth animation. object-fit: cover ensures images fill their containers properly. box-shadow and border-radius add visual polish to cards.

JavaScript is not used on this page. All interactivity comes from CSS hover effects only. The image overlay that reveals student names on hover, the subtle zoom effect on images, and the card shadows are all achieved with pure CSS. No form validation, dynamic content loading, or event handling is implemented.

Accessibility

All images include descriptive alt text with student names. The page uses semantic HTML elements like <header>, <main>, <footer>, and <ul> for proper document structure. The active page link is highlighted in the navigation bar. Heading hierarchy starts with <h1> for the main title, then <h3> for student names inside cards. The entire card is clickable as an <a> tag, making it keyboard accessible. Color contrast meets readability standards.
